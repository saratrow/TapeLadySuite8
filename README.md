# Tape Lady Business Suite — Sprint 2 v0.2

This release adds the first complete customer-to-project workflow.

## Working features

- Multi-page Customer and Project Wizard
- Create a new customer or select an existing customer
- Create the first project at the same time
- Automatic project folder creation
- Activity timeline entries
- Recent-project dashboard
- Persistent SQLite migration
- Safe coexistence with the existing Receipt Manager
- Windows launcher

## First run

1. Confirm GitHub Desktop is on `dev`.
2. Close TLBS.
3. Back up the project folder.
4. Copy this package into the project root, replacing files when prompted.
5. Double-click `RUN_TLBS.bat`.
6. Click `+ New Customer / Project`.
7. Complete the wizard.
8. Confirm the customer, project, activity, and project folder appear.

The existing Receipt Manager database and receipt files are not modified.
