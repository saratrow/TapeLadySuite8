# Integration Instructions

Run `RUN_TLBS_FOUNDATION.bat`.

Expected result:
- A dark TLBS dashboard opens.
- Six module cards appear.
- `+ New Customer` saves a customer.
- Closing and reopening preserves that customer.

After the test succeeds, commit on `dev` with:

`Create TLBS foundation dashboard and core database`

This pack does not rename or move the existing Receipt Manager yet.
